# Зал

Личный дневник тренировок и метрик тела. PWA, работает офлайн. Весь интерфейс на русском.
Статический сайт: vanilla HTML/CSS/JS (ES-модули), без сборки, без зависимостей. Данные хранятся в IndexedDB на устройстве.

## Локальный запуск
```
python3 -m http.server 8080     # или: npx serve .
```
Откройте http://localhost:8080. Через `file://` приложение не заработает: ES-модули и service worker требуют http.

## Деплой
Корень репозитория и есть сайт (статика, без сборки). Работает на любом статическом хостинге.

**Важно про `sw.js`:** он обязательно должен отдаваться с `Cache-Control: no-cache`, иначе CDN
хостинга может закэшировать старую версию и новые деплои не будут доходить до пользователей
(симптом: сайт то работает, то ломается с `ERR_FAILED` после переустановки сервис-воркера).

- **Vercel**: `vercel.json` в репозитории уже это делает.
- **Cloudflare Pages**: файл `_headers` в репозитории уже это делает (Cloudflare не читает `vercel.json`).
- **Другой хостинг**: убедитесь, что для `sw.js` выставлен `Cache-Control: no-cache` — проверьте
  в DevTools → Network → sw.js → Response Headers.
После изменения файлов увеличьте `VERSION` в `sw.js`, иначе установленное приложение продолжит показывать старую версию.

## Ограничение таймера
Без push-сервера браузер не может гарантированно показать уведомление, если телефон заблокирован.
Android обычно показывает уведомление о конце отдыха, iOS почти никогда. При возврате в приложение
панель таймера показывает, сколько времени назад закончился отдых.

## Тесты
`tests/e2e.cjs`: смоук-тест на Playwright при ширине 360 px (логгер, метрики, фото, графики, поиск,
экспорт → сброс → импорт, офлайн). Запуск: поднять сервер на :8765, затем `node tests/e2e.cjs`.

Шрифты Onest и Unbounded распространяются по лицензии SIL OFL 1.1.
